# Palab 手动制作谱面指南

> 最后更新：2026-07-26 | 版本 0.3.5

---

## 1. 概述

手动制作模式允许用户通过「跟随节拍按键」的方式录入谱面音符，系统自动进行节拍对齐、双押识别和难度评定。

### 完整流程

```
主菜单 → 制作谱面 → 手动制作
  → 选择音频 + 轨道数
  → 跟随节拍按键录入
  → 自动分析（节拍对齐 / 双押识别 / 难度评定）
  → 编辑器（标题 / 封面 / 曲绘 / 保存 zip）
```

---

## 2. 第一步：选择音频与设置

在 `ManualConfig` 界面：

1. **选择音频文件**（mp3/wav/ogg 等）— 系统自动分析 BPM
2. **选择轨道数**（2K / 4K / 6K / 8K）
3. 点击「开始录入」

> **注意：** 手动制作没有难度选择——难度由系统根据录入结果自动评定。

---

## 3. 第二步：录入音符

### 3.1 按键映射

| 轨道数 | 按键 |
|--------|------|
| 2K | `F` `J` |
| 4K | `D` `F` `J` `K` |
| 6K | `S` `D` `F` `J` `K` `L` |
| 8K | `A` `S` `D` `F` `J` `K` `L` `;` |

同时支持**键盘**和**鼠标点击**屏幕上的按键。

### 3.2 音符类型

| 操作 | 识别结果 | 条件 |
|------|----------|------|
| 短暂按下 | **Tap** | 按下 < 120ms |
| 长按不放 | **Hold** | 按下 >= 120ms |

**自动截断：** Hold 超过 2 秒自动结束，防止误触导致的超长音符。

### 3.3 录制控制

- **开始**：点击「开始」按钮，音乐开始播放
- **完成**：音乐播完自动结束，或点击「完成」提前结束
- **退出**：按 ESC 或点击「退出」弹出确认窗
  - 「继续录制」— 返回
  - 「退出」— 丢弃数据，返回模式选择

> **录制中不支持暂停。** 按 ESC 只能选择退出或继续。

### 3.4 界面元素

| 元素 | 位置 | 说明 |
|------|------|------|
| 进度条 | 顶栏中间 | 白色进度条，随音乐推进 |
| 时间 | 顶栏右侧 | `当前时间 / 总时长` |
| 音符计数 | 主体区域 | 「X 个音符」实时计数 |
| 节拍指示 | 主体区域 | 白色圆点脉冲动画 |
| 按键区 | 底部 | 按下时高亮变亮 + 缩小反馈 |

---

## 4. 第三步：自动分析

录入完成后进入 `ManualAnalyzer`，系统按顺序执行三项分析：

### 4.1 节拍对齐

- 基于 BPM 生成**半拍网格**（beatInterval / 2）
- 每个音符吸附到最近的网格点
- **偏差阈值**：正负 0.38 拍（约 1/3 拍）
- 超出阈值的音符保持原位（尊重用户意图）

### 4.2 双押识别

- 窗口：**35ms**
- 同一窗口内不同轨道的音符标记为多押组
- 设置 `isDouble = true` 和共享的 `doubleGroupId`

### 4.3 难度评定

基于四项指标自动计算定数（1.0~18.0）：

| 指标 | 说明 |
|------|------|
| NPS（音符密度） | 每秒音符数 |
| 双押比例 | 多押音符占比 |
| Hold 比例 | 长按音符占比 |
| 峰值密度 | 1 秒窗口最大音符数 |

详细公式见 [`math.md`](./math.md)。

---

## 5. 第四步：编辑与保存

分析完成后进入 `ChartEditor`，与自动分析流程完全相同：

1. **编辑元信息**：标题、曲师、谱师、描述
2. **上传封面**：列表展示和加载界面使用
3. **上传曲绘**：游玩时模糊背景使用
4. **保存**：导出为 `.zip` 包

Zip 包格式详见 [`file-formats.md`](./file-formats.md)。

---

## 6. 与自动分析的对比

| 特性 | 自动分析 | 手动制作 |
|------|----------|----------|
| 音符来源 | AI 基于音频峰值生成 | 用户按键录入 |
| 难度定数 | 用户手动选择 | 系统自动评定 |
| 节拍对齐 | 无需（AI 直接放在节拍上） | 自动吸附到节拍网格 |
| 适用场景 | 快速生成，批量创作 | 精细控制，表达创作意图 |
| 长条支持 | AI 随机生成 Hold | 长按即可录入 Hold |

---

## 7. 使用建议

- **先听一遍歌曲**，熟悉节奏和结构
- **BPM 尽量准确**，影响节拍对齐质量
- **Hold 用于长音**，和弦、延长音等
- **多押不要太密**，自动识别窗口 35ms，故意错开一点可以避免误判
- **不满意可以重录**，按 ESC 退出后重新选择歌曲开始
