# Palab 谱面库 · 社区简介编写指南

本指南说明如何在 **lingyanspace** 后台为游戏谱面库（`softwareId = 53303667563959301`）上传谱面时，正确填写"简介"，让游戏内的 **谱面库 → 社区** 面板能正确解析、展示、搜索、筛选和排序你的谱面。

---

## 一、一个"谱面" = lingyanspace 上的一个"版本"

在 lingyanspace 后台，游戏谱面库软件下**每添加一个版本，就是一条社区谱面**。上传时需要填写的关键字段与游戏内的对应关系如下：

| lingyanspace 字段 | 游戏内用途 | 必填 |
|---|---|---|
| **版本号 / 名称（versionNum）** | 谱面标题（列表和详情页显示、标题搜索、按标题排序） | ✅ |
| **版本说明 / 简介（versionDes）** | 曲师 / 谱师 / 难度 / 定级 / 简介（本指南重点） | ✅ |
| **安装包（文件，上传 zip）** | 谱面包下载（fileUrl / fileSize 由平台自动生成） | ✅ |
| packageStatus | beta / release（谱面库面板不区分，均可显示） | 可选 |

> 注意：**下载次数（downloadCount）由平台自动累计**，无需手动填写。

---

## 二、简介（versionDes）的两种写法

游戏用 `parseChartMeta` 解析 `versionDes`，**优先尝试 JSON 格式，失败后自动改走"行式键值对"格式**。二选一即可，推荐用**行式**（可读性更好）。

### 方式 A：行式键值对（推荐）

每行写一个 `键：值`，用英文冒号 `:` 或中文冒号 `：` 分隔即可：

```
曲师：Sheep
谱师：ColaSensei
难度：HD
定级：14.7
简介：这是一张演示谱面，下落式音游，适合新手练习。
```

> 键的**顺序无关**、**大小写无关**（英文键），中英文键都可混用。除下列键外的其他行会被忽略，可以自由写备注。

### 方式 B：JSON 格式

```json
{
  "artist": "Sheep",
  "author": "ColaSensei",
  "difficulty": "HD",
  "constant": 14.7,
  "description": "这是一张演示谱面，下落式音游，适合新手练习。"
}
```

## 三、可识别的键名对照表

| 含义 | 可写的键（任选其一） |
|---|---|
| **曲师** | `曲师`、`artist` |
| **谱师** | `谱师`、`author`、`mapper` |
| **难度** | `难度`、`difficulty` |
| **定级（定数）** | `定级`、`定数`、`constant`、`chartconstant`、`chart_constant` |
| **简介** | `简介`、`desc`、`description` |

## 四、字段填写注意事项（重点）

### 1. 难度必须用标准值：`EZ / NM / HD / IN / AT`

社区面板的**难度筛选**按**精确相等**匹配（如 `EZ` 只匹配 `EZ`）。解析时仅做大写转换，**不会**把"简单""中等""困难"等中文词翻译成标准难度。请直接写标准值之一：

```
难度：EZ     → 正确
难度：简单   → 不会被筛选识别（面板按大写转换后仍不等于 EZ/NM/HD/IN/AT）
```

如果确实没有难度分级，**这一行可以省略**（详情页只显示曲师/谱师）。

### 2. 定级（定数）建议写小数

面板按"定数"排序，并显示为一位小数（如 `14.7`）：

```
定级：14.7
```

- 可写整数或小数，如 `15`、`15.6`。
- 不写则定数视为 `0`，按定数排序时排在最后。

### 3. 曲师 / 谱师 建议与谱面文件内信息一致

社区面板用 **标题 + 曲师 + 谱师 + 难度 完全匹配** 来判断你是否"已拥有"该谱面。

- 若你本地谱面包里的曲师/谱师与社区简介不一致，即使下载过，面板也可能不显示"已拥有"。
- 建议简介里的曲师/谱师与谱面文件（`.zip` 内 chart 的 artist / author）保持一致。

### 4. 简介支持多行

`简介` 的值可以包含换行，详情页会保留换行显示：

```
简介：第一行说明。
第二行补充玩法提示。
```

### 5. 其他字段由平台自动处理

- **zip 下载地址（fileUrl）**：上传安装包后自动生成。
- **文件大小（fileSize）**：自动生成，面板按 KB / MB / GB 显示。
- **下载次数**：自动累计，无需填写。

## 五、完整示例

### 行式写法（推荐）

```
版本名称：夜航星 Night Voyage
版本说明（versionDes）：
曲师：Tino.S3
谱师：ColaSensei
难度：IN
定级：15.6
简介：高速互动谱面，注意长条尾判。适合 15 级左右玩家挑战。
```

### JSON 写法

```json
{
  "曲师": "Tino.S3",
  "谱师": "ColaSensei",
  "难度": "IN",
  "定级": 15.6,
  "简介": "高速互动谱面，注意长条尾判。适合 15 级左右玩家挑战。"

```

## 六、上传后检查清单（社区面板显示不出来的排查）

1. **软件 ID 是否正确**：谱面必须上传到 `53303667563959301`（不是公告用的那个）。
2. **是否成功添加版本**：游戏社区面板只拉取该软件下的版本列表；如果从未上传过任何版本，面板会显示"暂无社区谱面"。
3. **`versionNum` 是否填写**：为空会显示为"未知谱面"。
4. **简介格式是否正确**：键名要符合第三节对照表；行式写法确保 `键：值` 在同一行，用英文或中文冒号分隔。
5. **难度筛选不出来**：确认难度写的是 `EZ/NM/HD/IN/AT` 之一，而不是中文词。
6. **下载后不显示"已拥有"**：确认本地谱面的曲师/谱师/标题/难度与社区简介完全一致（含大小写、空格）。
7. **改了之后仍不生效**：游戏每次进入谱面库社区都会重新拉取；确认游戏已刷新、网络正常（离线时社区无法加载）。

## 附：解析规则速查（供开发者参考）

- 解析函数：`parseChartMeta(versionDes)`（`src/utils/lingyanspace.ts`）
- 解析顺序：先尝试 `JSON.parse`；失败则按行 `^\s*键\s*[:：]\s*值` 匹配，键去空格、转小写后对照 `META_KEYS`。
- 难度：值统一 `toUpperCase()`；定数：`parseFloat` 取数。
- 已拥有判定：`标题 || 曲师 || 谱师 || 难度` 四字段完全一致。
